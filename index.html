📚 Lesson 1: Your First Python Command

Before we start writing code, let's understand what Python actually does.

🐍 What is Python?

Python is a programming language that allows us to give instructions to a computer.

Think of a computer as someone who follows the instructions you provide

💻 What is the print() function?

The print() function tells Python to display something on the screen.

For example, if you want Python to display "Hello, world!", we write:

print("Hello, world!")
🖥️Output:
Hello, world!

🔎 Let's Understand the Command

Our first command has three important parts:

  • 🟦print - tells Python to display something.
  • 🟨()Parentheses - hold the information we want to display.
  • 🟩" "Quotation marks - show the Python that text is a string
💡What is a string?

A string is a sequence of characters, such as letters, words, or sentences.

Example:"Hello, world!"

Remember: Python needs quotation marks around text that you want to display as a string.

📦 Lesson 2: Variables and Datab Types

Welcome back, future programmers! In our first lesson, we learned how to use Python's print() function to display messages on the screen.

But imagine that we want Python to remember someone's name, age, favorite color, or test score. Writing everything inside print() would become difficult.

This is where variables come in! Variables allow us to store information and use it whenever we need it.

💡What Is a Variable?

A variable is a named place where Python stores information.

Think of a variable as a box with a label. The label tells us what information the box conatins

For example, imagine that you have three boxes:

  • A box labeled name contains "Shahzada". "
  • A box labeled age contains 17.
  • A box labeled city contains "Dashoguz"

In Python, we can represent these boxes using variables.

name = "Shahzada"
age = 17
city = "Dashoguz"

We have created three variables. Each variable stores a different value.

🔎 2. Understanding How Variables Work

Let's examine this statement.

name = "Shahzada"

It has three important parts:

  • name - the variable name.
  • = - the assignment operator. It assigns a value to the variable.
  • "Shahzada" - the value stored in the variable.
⭐Remember: The equal sign in Python assigns a value. It does not always mean that two things are equal in the mathematical sense.

🚀 3. Your First Variable Example

Let's create a variable called favorite_color and store color inside it.

favorite_color = "violet"
print(favorite_color)
💻 Output:
violet

What happened?

  1. Python created a variable named favorite_color
  2. It stored the value "violet" inside it.
  3. The print() function displayed that value.

Notice that we wrote print(favorite_color), not print("favorite_color")

Without quotation marks, Python understands that we want the value of the variable. With quotation marks, Python displays the actual word.

favorite_color = "violet"
print(favorite_color)
print("favorite_color")
💻 Output:
violet
favorite_color
💡 This is an important difference! Remember it as you continue learning Python.
